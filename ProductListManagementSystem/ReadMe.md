# ProductListManagementSystem

ProductListManagementSystem is a c# program for handling products with categories.

## Installation

Download the source code from the GitHub repository.
https://github.com/Spacebearswe/ProductListManagementSystem


## Usage

```p
Enter products into the console, and the program will manage the list of products for you.
You can add, delete, edit, remove, view and see statistics for products in the list.
Load and save the list of products to a file for later use.
```
```p
Product Management System

Enter a Number
1-Add a Product
2-Search a Product
3-List Products
4-Remove Product
5-Update Product
6-Show Statistics
7-Load Products
8-Save Products
0-Quit
Enter a Number
```
